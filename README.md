# SCD Group 11 – Tennis Refactoring

## Project Description
This project is part of the Software Construction and Development (SCD) course.

The purpose of this project is to refactor an existing Python-based Tennis Scoring System to improve its internal code structure, readability, maintainability, and object-oriented design while preserving its original external behaviour.

## Project Objectives
- Identify at least five code smells.
- Apply Fowler's refactoring techniques.
- Simplify complex conditional logic.
- Extract and organize tennis scoring rules.
- Write characterization tests.
- Use Git and GitHub for version control.
- Manage changes through feature branches and pull requests.

## Technology Used
- Python
- Git
- GitHub
- Pytest
- UML Class Diagrams

## How to Run the Project

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Install the required dependencies.
5. Run the Python Tennis Scoring System.

## Testing

We will use Pytest to verify that the original behaviour remains unchanged after each refactoring.
